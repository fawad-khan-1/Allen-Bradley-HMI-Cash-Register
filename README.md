# Allen-Bradley PLC & HMI Cash Register System

This project implements a PLC-controlled Human-Machine Interface (HMI) for a fictional fast-food restaurant cash register. It was developed as part of a university industrial automation course using Allen-Bradley PLC and HMI equipment.

The project combines PLC ladder logic with an HMI interface that allows a user to select menu items and calculate an order total. The completed system was implemented and tested using physical PLC and HMI equipment available in the university automation laboratory.

## Project Features

- Allen-Bradley PLC programming
- Ladder Logic
- HMI interface development
- HMI buttons for selecting menu items
- PLC/HMI tag communication
- Order price calculations
- Sales tax calculation
- Display of the final order total
- Physical PLC and HMI implementation

## System Operation

The HMI was designed to simulate a cash register for a fictional fast-food restaurant.

The user can select different menu items through the HMI interface. The selections interact with the PLC program, which performs the required calculations and updates the information displayed through the HMI.

## Project Purpose

The purpose of this project was to gain hands-on experience integrating PLC programming with HMI development using the Allen-Bradley automation platform.

The project provided experience with PLC ladder logic, HMI development, PLC/HMI communication, and testing an automation application on physical industrial control hardware.
